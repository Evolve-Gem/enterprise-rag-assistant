## 目标 1 — 30 秒：知道这是什么

| 检查项 | 实测 |
| --- | --- |
| 首屏出现价值主张「让企业知识从…」 | ✅ |
| 首屏出现副标题「基于企业知识库，实现可溯源知识问答…」 | ✅ |
| 技术 Badge 存在且低权重 | ✅ `Hybrid RAG` / `LangGraph` / `公开只读 Demo` |
| **三张核心入口卡片是否在首屏（1440×900，无需滚动）** | ✅ **3/3 全部在视口内** |
| 卡片文字是否用的是业务语言 | ✅ 「知识问答 向企业知识库提问，AI 会先检索资料，再基于真实证据回答。」 |

实测抓到的首屏卡片内容：

```
知识问答 Ask     向企业知识库提问，AI 会先检索资料，再基于真实证据回答。      开始提问
AI 任务 Agent Workspace  告诉 Agent 你想完成什么，它会自动识别任务并调用对应能力。  运行 Agent
方案生成 Solution Studio  输入客户需求，自动形成结构化、可溯源的售前方案。      生成方案
```

**结论：30 秒内可判断"这是一个基于企业知识做可溯源问答 / AI 任务 / 方案生成的产品"。**

> 口径说明：自动检查里有一项 `asksForExplanation` 判为 true，原因是页面**技术 Badge 行**含 "RAG" 字样。
> 该行是 Freeze 要求"降权展示"的技术标签，不是标题；主标题与副标题均为业务语言，无工程术语。
> 此项不计为缺陷，也不虚报为通过项。

## 目标 3 — 3 分钟：完成一次真实体验

沿着页面**自己的** Step 1 链接走完整条路（这同时验证预填传递）：

| 步骤 | 实测 |
| --- | --- |
| Step 1 链接指向 | ✅ `/ask?q=Rerank%20%E5%9C%A8%20RAG%20...`（URL 编码正确） |

| 是否**自动提交** | ✅ **未自动提交**（符合"让用户自己点击发送"） |

**结论：3 分钟内可在不看任何说明的情况下完成一次真实的知识问答，并看到来源依据。**
