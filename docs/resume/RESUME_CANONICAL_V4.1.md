## 1.5 RAG 架构（四层检索）

| 层 | 组件 | 关键实现 |
| --- | --- | --- |
| ① 索引 | KnowledgeIndex | Markdown 标题切 section + 标题栈；段落级打包至 **chunk_size = 500 字符**；真实字符重叠 **100 字符**；超长段落按句末边界硬切 |
| ② 检索 | BM25 + 向量 | BM25 **字段加权**：文件名 + 章节路径 + 正文；向量默认离线哈希 TF-IDF，可切任意 OpenAI 兼容 embeddings |
| ③ 融合 | RRF | **默认 RRF 而非加权求和**（BM25 分与余弦相似度不同量纲，加权需标定且参数会漂移） |
| ④ 重排 | heuristic | **IDF 加权覆盖度** + 短语 + 章节 + 密度 |
| ⑤ 生成 | Grounded | 编号上下文 → Prompt 声明「编号即引用命名空间」→ 生成 → **引用校验剔除越界编号** |

| 关键参数 | 值 |
| --- | --- |
| 召回宽度 | **`top_k = 8`** |
| 重排后进入 Prompt | **`rerank_top_k = 4`** |
| 知识库规模 | **24 篇文档 / 283 个知识块 / 58,524 字符** |
| 可替换配置项 | `EMBEDDING_PROVIDER` / `RETRIEVER_MODE` / `FUSION_STRATEGY` / `RERANK_PROVIDER` / `VECTOR_STORE` |
