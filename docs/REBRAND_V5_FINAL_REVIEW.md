## 6 ｜ V5 与 V4.2 的核心差异

1. **框架材质**：白框 → 恒定深墨框架（两主题），品牌第一感知点
2. **旗舰瞬间**：玻璃卡 → Stage 材质（Hero / masthead / 控制台 / 流程条 / 全部结果头带）
3. **首页结构**：三漂浮卡 + 两组三卡片 → 连通 Rail + 示例列表 + 编号流水线 + 仪表盘
4. **排版**：Hero 26/32 → 27/36/40；页头 17 → 20 + kicker；展示级数字
5. **信号色**：极光只上墨面（active/签名线/氛围），浅面永不受染
6. **可感知度**：Before/After 对照（`02_V42_V5_BEFORE_AFTER/` 7 组）为像素级证据
