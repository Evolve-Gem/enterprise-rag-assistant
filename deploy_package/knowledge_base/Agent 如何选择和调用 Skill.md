# Agent 如何选择和调用 Skill

## 核心结构

用户需求
→ 意图识别
→ Skill 路由
→ 参数收集
→ Skill 执行
→ 结构化输出
→ 人工复核

# 三个概念

Skill：一种可复用业务能力。

Workflow：多个步骤按照固定顺序执行。

Agent：根据任务选择 Skill 或 Workflow，并组织最终结果。

一句话：

==Skill 是能力，Workflow 是流程，Agent 是决策和调度。==

**Workflow 描述为由预先设定的代码路径来编排模型和工具；而 Agent 则由模型动态决定过程和工具使用**

# main.py 的职责

- 接收用户输入
- 识别用户意图
- 选择对应 Skill
- 收集输入参数
- 调用 Skill
- 处理错误
- 返回最终结果

# 当前 Agent 类型

当前使用关键词识别意图，属于基于规则的轻量 Agent。

优点：

- 简单
- 稳定
- 容易测试
- 结果可解释

缺点：

- 无法理解复杂表达
- 需要人工维护关键词

后续可以用 LLM 替换意图识别模块。

# 关键工程思想

因为各模块相互独立，所以未来升级意图识别时，不需要重写销售日报 Skill。
