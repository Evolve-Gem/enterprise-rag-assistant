## 本轮修掉的真实缺陷（都被测试/诊断抓出来）

1. **CJK 单字噪声**：`在/里/解/什/么` 参与 BM25 打分 → `RAG.md` 21.95 分压过真正定义
   Rerank 的文档（15.17，且完全不在候选集）。改 CJK 二元组 + 停用词表。
2. **文件名从未进索引**：`召回、Top K、Rerank 与 RAG 检索链路.md` 文件名零权重。
   加 `searchable_text()`（文件名 + 章节 + 正文）。
3. **重排序覆盖度等权**：稀有判别词与高频虚词同权 → 改 **IDF 加权覆盖度**。
4. **评测数据集无限递归**：`load_dataset` ↔ `seed_dataset` 互调。拆 `_read_cases()`。
5. **活动台账凭据过滤漏网**：精确匹配放过 `secret_key` / `credential` → 改字段名分段正则，
   并白名单 `tokens_used` 等合法计数器。
6. **pytest 无法导入 app**：仓库根 legacy `app.py` 遮蔽后端 `app` 包（报错里混着 Streamlit 警告）。
   删后端 `__init__.py`，让 pytest 只把 `backend` 入路径。
7. **前端 `useAsync` 类型缺陷**：对象展开丢失可辨识联合收窄；闭包内属性收窄失效。

### 本轮修掉的 4 个真实缺陷（2 个 High）
1. **HIGH｜23 个响应式 grid 缺 base 列定义** → 低于断点时隐式轨道按 max-content 撑开，
   卡片被撑到 1451px → **1080 宽度横向溢出 635px**（1080p 是演示常用分辨率）。
   修法：给所有 `grid` 容器补 `grid-cols-1`（= `repeat(1, minmax(0,1fr))`，
   `minmax(0,…)` 才是把轨道钉在容器宽度上的关键）。
2. **HIGH｜`DEMO_PASSWORD` 只护住写入与查询，全部读取端点匿名可读**
   （文档/概览/设置/洞察/评测/台账/Agent 目录/检索）→ 口令保住了「查询」却漏掉「原始知识库」。
   修法：改为**中间件级鉴权门 + 公开路径白名单**，而不是逐路由依赖（逐路由必然漏）。
3. **MED｜Overview 显示配置值 `auto`，顶栏显示生效值 `langgraph`** → 同屏自相矛盾。
4. **MED｜只读模式未拦 `POST /api/knowledge/reindex`**（200），与 README 声明矛盾。
附加：Topbar 状态徽标不可收缩 → `max-sm:hidden`，移动溢出 102 → 27px。

### ⚠️ 本轮最惨痛教训：差点毁掉语料
用 `git ls-files` 做差集来「删除未跟踪文件」，但 `git ls-files` 对**非 ASCII 路径输出八进制转义**，
导致 22 篇中文文档被误判为「未跟踪」并被删除（24 → 3 篇）。
`git restore knowledge_base/` 全部恢复，字节数校验通过，零数据丢失。

**硬性规则（已写入 MEMORY.md）**：
- 程序化消费 `git ls-files` / `git status --porcelain` **必须**加 `-z` 或 `-c core.quotepath=false`。
- **禁止用差集推导删除目标**；只删除**明确列举**的产物，删除前先打印清单并核对数量。

### 环境坑（新增）
