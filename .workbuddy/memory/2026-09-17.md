## 本轮修掉的真实缺陷（都被测试/诊断抓出来）

1. **CJK 单字噪声**：`在/里/解/什/么` 参与 BM25 打分 → `RAG.md` 21.95 分压过真正定义
   Rerank 的文档（15.17，且完全不在候选集）。改 CJK 二元组 + 停用词表。
2. **文件名从未进索引**：`召回、Top K、Rerank 与 RAG 检索链路.md` 文件名零权重。
   加 `searchable_text()`（文件名 + 章节 + 正文）。
3. **重排序覆盖度等权**：稀有判别词与高频虚词同权 → 改 **IDF 加权覆盖度**。
4. **评测数据集无限递归**：`load_dataset` ↔ `seed_dataset` 互调。拆 `_read_cases()`。
5. **活动台账凭据过滤漏网**：精确匹配放过 `secret_key` / `credential` → 改字段名分段正则，
   并白名单 `tokens_used` 等合法计数器。
6. **pytest 无法导入 app**：仓库根 legacy `app.py` 遮蔽后端 `app` 包（报错里混着 Streamlit 警告）。
   删后端 `__init__.py`，让 pytest 只把 `backend` 入路径。
7. **前端 `useAsync` 类型缺陷**：对象展开丢失可辨识联合收窄；闭包内属性收窄失效。
