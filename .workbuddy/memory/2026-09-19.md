## 关键判断：无密码模式本来就存在

`require_auth`（`api/deps.py`）在 `demo_password` 为空时直接 `return`；中间件门的
`needs_token = bool(settings.demo_password) and ...`；前端 `app-shell.tsx:36` 依
`password_required=false` 跳过登录页。**三项均已存在**，所以本次是「改配置」而非「改代码」。

**教训**：把一个既有能力显式写成「受支持的模式」，比让它作为隐式行为存在更有价值 ——
否则下一个人会以为空值是配置漏填，然后「顺手修好」它。

## 限流设计（`backend/app/core/ratelimit.py`，新增）

- **滑动窗口而非固定窗口**：固定窗口允许客户端在边界两侧打 2×limit，正是刷额度的人会找的缝。
- **客户端数上限 4096** + 每次访问剪枝，伪造 IP 洪泛撑不爆 dict。
- **范围用精确匹配不用前缀**（见下方坑 1）。
- 默认 `RATE_LIMIT_ENABLED=false`，本地与测试永不被限流。

## 两个用测试逼出来的坑（都写了回归测试）

**坑 1：前缀匹配误伤浏览端点。**
`/api/solutions/` 前缀把 `/api/solutions/config`（Solution Studio 表单的只读配置）也圈进来了。
给只读页限流正是「演示感觉坏了」的典型失败。改为显式精确集合。

**坑 2：Starlette 的 `@app.middleware` 是 PREPEND，最后声明的在最外层。**
实测中间件链：`_timing → _demo_rate_limit → _demo_password_gate → route`。
所以限流跑在鉴权门**外面** —— 匿名调用者可以烧掉它正在冒充的那个 IP 的额度，
等于一次廉价的定向 DoS。修法：限流中间件自己重放一次鉴权判断，将被 401 拒绝的请求不计费。

**通用教训**：不要凭记忆推断 ASGI 中间件顺序，**打印 `app.user_middleware` 看真的**。

## 修掉的既有 bug：`docker/Dockerfile.web` 的 NPM_REGISTRY 从未可用

`sed "s#https://registry.npmjs.org/#${NPM_REGISTRY}#g"` 吃掉了尾部斜杠，替换串没补回来 →
`https://registry.npmmirror.comzwitch/...` → `getaddrinfo ENOTFOUND registry.npmmirror.comzwitch`。

**实测带宽差距**：本机 pypi.org 约 18 KB/s、清华镜像 4.4 MB/s；npm 上游 146 KB/s、npmmirror 49 MB/s。
修复后 backend 镜像构建从**卡死 20 分钟以上**降到 **21 秒**。提交 `8725620`。

**教训**：把「快速路径」也跑一遍。没人踩过这个坑，是因为没人真的用过它 ——
而它恰恰是大陆主机上唯一可用的路径。

## 服务器构建坑：`docker compose build` 经 SSH 会静默卡死

直接 `ssh ... "docker compose build"` 时，SSH 客户端断开后远程进程**仍在跑但 buildkit
会话已失效**，表现为 `load average ≈ 0`、无 `runc` 进程、镜像不更新 —— 看起来像卡住，其实死了。

**可靠姿势**：

```bash
ssh host "cd repo && rm -f /tmp/b.log && setsid nohup docker compose build backend > /tmp/b.log 2>&1 < /dev/null & disown; echo LAUNCHED"
# 之后单独 ssh 读 /tmp/b.log 判断进度（tail + pgrep）
```

不要把构建放在 `tail` 管道里等 —— stdout 被缓冲，什么都看不到。

## CDP 浏览器脚本的三个 bug（`C:\agents\temp\cdp.mjs` 已修）

1. **`launch()` 后 `evaluate` 必失败**：`about:blank` 的执行上下文未提交，`Runtime.evaluate`
   返回 `Invalid parameters (-32602)`。修法：launch 末尾导航到 `data:text/html,...` 并轮询直到 evaluate 可用。
2. **`evaluate(function)` 直接把函数当 expression 传**：函数对象序列化后为空 → `-32602`。
   修法：`typeof fn === 'function'` 时 `` `(${fn.toString()})()` ``，并支持 `evaluate(fn, [args])`。
3. **`send()` 的 rejection 在 `await` 挂载前到达 → 未处理拒绝直接杀进程**。
   修法：`promise.catch(() => {})` 标记已处理，原错误仍传给真正的调用方。

**另外**：探针脚本里我猜的路由全错（`/solutions`、`/evaluation` 是 404，真实路径是
`/solution-studio`、`/insights/evaluation`）。**路由要从渲染后的 `a[href]` 提取，不要凭记忆猜。**
引用标记是 `#N` 不是 `[N]`。
